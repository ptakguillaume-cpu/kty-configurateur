Ajouter un produit à la liste

Cherchez par nom ou par code (ex. « goulotte 3000 », « huisserie AB 837 », « Z-DIV »). Le produit est ajouté à la liste CODE / Désignation / Qts, avec une désignation abrégée que vous pouvez modifier.
